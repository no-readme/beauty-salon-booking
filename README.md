# Система онлайн-записи для салона красоты

Система предназначена для онлайн-записи клиентов салона красоты и ведения единого актуального расписания мастеров. Клиент самостоятельно выбирает услугу, мастера и свободное время, а система исключает пересекающиеся записи и напоминает о предстоящем визите. Администратор управляет записями и каталогом услуг, а владелец получает статистику загрузки мастеров и востребованности услуг.

## Пользователи

- **Клиент** — записывается на услуги, отменяет и переносит свои записи.
- **Мастер** — просматривает своё расписание и отмечает время, когда недоступен.
- **Администратор** — ведёт все записи, расписание мастеров и каталог услуг.
- **Владелец** — просматривает статистику загрузки мастеров и востребованности услуг.

## Основные возможности

- Каталог услуг с продолжительностью и стоимостью
- Онлайн-запись с выбором услуги, мастера и свободного времени без пересечения записей
- Подтверждение записи и SMS-напоминание за 24 часа до визита
- Отмена и перенос записи клиентом не позднее чем за 2 часа до начала
- Раздел администратора: все записи, расписание мастеров, каталог услуг
- Раздел мастера с собственным расписанием
- Статистика загрузки мастеров и востребованности услуг для владельца
